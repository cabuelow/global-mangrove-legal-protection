### Global laws and policies protecting mangroves

This repository contains code and data to reproduce analyses and figures for *[Slobodian et al. 2025. Quantifying the presence and potential of national legal frameworks for global mangrove protection. Cell Reports Sustainability. https://doi.org/10.1016/j.crsus.2025.100430](https://www.cell.com/cell-reports-sustainability/fulltext/S2949-7906(25)00126-0?_returnURL=https%3A%2F%2Flinkinghub.elsevier.com%2Fretrieve%2Fpii%2FS2949790625001260%3Fshowall%3Dtrue)*.

#### Scripts

##### Main analyses and scripts

**1. 01_maps-time-series**: Map and plot laws and policies

**2. 02_model-associations**: Run a multivariate Bayesian hierarchical model of associations between socio-ecological conditions and mangrove law/policy adoption

##### Other

make-national-covariate-db.R: This script combines all covariate data into a single dataframe for the analysis `national-master.csv`
